# My OpenCode Skills

Custom skills for OpenCode AI assistant.

## Installation

Clone this repo to your skills directory:

```bash
git clone https://github.com/carlo/my-opencode-skills.git ~/.config/opencode/skills/
```

## Skills

### feature-creator

Guide for creating features in senasa-casilla-frontend following project conventions.

**Trigger:** crear feature, nueva feature, feature structure, feature scaffold

## Updating

```bash
cd ~/.config/opencode/skills/my-opencode-skills
git pull
```
